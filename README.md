# Cocktails API

The Cocktails API serves as the backend system for the [cocktails-website](https://github.com/nrasheva/cocktails-website), providing a set of endpoints to manage authentication, authorization, cocktails recipes, favorite recipes, etc.

## Features

- Authentication
- Authorization
- CRUD operations on recipes
- Manage favorite recipes

## Run locally

Clone the project

```bash
git clone https://github.com/nrasheva/cocktails-api
```

Go to the project directory

```bash
cd cocktails-api
```
Install the dependencies

```bash
npm install
```
Start the server

```bash
npm run start
```
